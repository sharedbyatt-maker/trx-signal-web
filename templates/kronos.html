    ✧ Kronos Research Notes

    Data source

    Uses the same existing BIG/SMALL round history as the main chart. No new market-price API.

    Model integration

    Real Kronos inference is not running on this web server. An isolated GitHub Actions workflow generates research snapshots outside the web server. Published snapshots load automatically; historical results are labelled separately. Scheduled runs may be delayed or unavailable.

    Important limitation

    Kronos is trained for financial OHLCV, not BIG/SMALL synthetic walks. Research results need honest walk-forward testing against simple baselines.

    Not a trading signal

    Never treat a projected round or backtest as a guaranteed outcome. Existing trade and admin logic remain unchanged.
